# 音乐聚合搜索 · Music Freedom

多平台音乐聚合搜索工具，支持在线试听。

## 使用方式

```bash
# 1. 安装依赖
npm install

# 2. 启动 API 服务（默认端口 3000）
npm start

# 3. 浏览器打开 music_hub.html
```

## 支持平台

- 网易云音乐
- QQ音乐
- 酷我音乐
- 酷狗音乐
- 咪咕音乐

## 技术栈

- 前端：原生 JavaScript + CSS3
- API：[NeteaseCloudMusicApi](https://github.com/Binaryify/NeteaseCloudMusicApi)
